## ❓ 問題

---

## 🔍 根本原因

**Freqtrade 更新了回測結果存儲格式：從 `.json` 改為 `.zip`**

原代碼只搜索 `.json` 文件，導致無法找到實際的回測結果。

---

## ✅ 解決方案

修改 `foundry/foundry_engine.py`，實現：

1. **支持 ZIP 格式** - 自動解壓並讀取內部 JSON 文件
2. **排除 meta.json** - 明確排除元數據文件
3. **擴展時間窗口** - 10秒 → 15秒
4. **向後兼容** - 同時支持 `.zip` 和 `.json`
