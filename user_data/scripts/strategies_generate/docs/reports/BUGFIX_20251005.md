### 問題 2: 'list' object has no attribute 'split'
**錯誤信息**:
```
ERROR: 'list' object has no attribute 'split'
```

**根本原因**:
- 第 323 行代碼錯誤: `code = parts.split('```')[0].strip()`
- `parts` 是列表，不是字符串，列表沒有 `split()` 方法

**影響範圍**:
- `strategy_factory.py` 第 323 行（代碼提取邏輯）
- 導致無法從 Gemini 輸出中提取策略代碼

**修復方案**:
```python
# 修復前
parts = result.stdout.split('```python')
if len(parts) > 1:
    code = parts.split('```')[0].strip()  # ❌ 錯誤！

# 修復後
parts = result.stdout.split('```python')
if len(parts) > 1:
    code = parts[1].split('```')[0].strip()  # ✅ 正確！
```

**修復位置**:
- ✅ 第 323-324 行: 添加註釋並修正索引

### 問題 3: TypeError - unhashable type: 'list'
**錯誤信息**:
```
TypeError: unhashable type: 'list'
File "strategy_factory.py", line 477, in evaluate_backtest
    scalping_data = strategy_data.get(strategy_name, {})
```

**根本原因**:
- 第 476 行: `strategy_name = list(strategy_data.keys())` 返回列表
- 第 477 行: 嘗試用列表作為字典的鍵 → 列表不可哈希，無法作為鍵

**影響範圍**:
- `strategy_factory.py` 第 476-477 行（回測評估）
- 導致無法評估任何回測結果

**修復方案**:
```python
# 修復前
strategy_name = list(strategy_data.keys())  # 返回列表
scalping_data = strategy_data.get(strategy_name, {})  # ❌ 錯誤！

# 修復後
strategy_name = list(strategy_data.keys())[0]  # 取第一個元素
scalping_data = strategy_data.get(strategy_name, {})  # ✅ 正確！
```

**修復位置**:
- ✅ 第 476 行: 添加 `[0]` 取列表第一個元素

### 問題 4: TypeError - 字符串與數字比較錯誤
**錯誤信息**:
```
TypeError: '<' not supported between instances of 'str' and 'int'
TypeError: '<' not supported between instances of 'str' and 'float'
```

**根本原因**:
- Gemini 生成的策略代碼可能包含字符串形式的數字
- 例如: `dataframe['slowk'] < '35'` 而不是 `dataframe['slowk'] < 35`

**當前狀態**:
- ⚠️ 這是 Gemini 生成代碼的質量問題
- ⚠️ 需要在 prompt 中更明確要求數字類型
- ⚠️ 或添加額外的代碼驗證步驟

**建議解決方案**:
1. **改進 Prompt** (推薦):
   - 在生成策略的 prompt 中明確要求使用數字而非字符串
   - 添加示例展示正確的比較語法

2. **添加代碼驗證**:
   - 在 `fix_talib_parameters()` 後添加數字引號移除函數
   - 使用正則表達式檢測並修復引號包裹的數字

3. **預執行檢查**:
   - 在回測前進行語法和類型檢查
   - 使用 Python AST 解析器驗證代碼正確性
