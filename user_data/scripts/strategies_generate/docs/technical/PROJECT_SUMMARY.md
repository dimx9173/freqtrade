
## ⚙️ 核心算法

### Foundry 篩選邏輯

```python
通過標準 = (
    最大回撤 < 7% AND
    月均交易 > 60 筆 AND
    勝率 > 50% AND
    利潤因子 > 1.2 AND
    夏普比率 > 1.0
)

三週期全部通過 → 晉升到候選池
```

### Refinery 晉升邏輯

```python
晉升條件 = (
    (夏普提升 > 20% OR 利潤提升 > 15%) AND
    優化後夏普 > 1.2
)

滿足條件 → 晉升到優化池
```

### War Room 決策邏輯

```
人工審核 → 決策：
  ✅ 畢業 (Graduate): 移至 graduated/
  ⚠️  退回 (Revert): 返回 candidate_pool/
  ❌ 淘汰 (Discard): 永久存檔
```
