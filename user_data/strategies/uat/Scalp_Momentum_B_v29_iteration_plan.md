### 假設：止損觸發的規律

**H1: 止損多發生在回調幅度過深的時候**
- pullback_min 設為 0.15%（極淺回調），可能導致進場時機已經是相對高點
- 當 pullback_pct 接近 pullback_min 時，反彈空間有限，遇到突發波動容易觸發止損

**H2: 止損多發生在 RSI 边界区（35-40 或 65-72）**
- RSI 在 35-40 是超賣邊界，反彈可能衰竭
- RSI 在 65-72 是偏熱區，追漲風險高

**H3: 止損多發生在成交量異常放大時**
- volume_mult=0.75 較低，可能在主力出貨時進場

## 五、v29 具體改進方向

### 改進 1：動態止損 - 根據 ATR 調整止損距離

**邏輯**：
- 現有固定 -2% 止損在低波動時可能過寬，在高波動時可能過窄
- 改用 ATR 倍數計算動態止損：stop_loss = -1.5 * atr_pct（最少 -1%，最多 -3%）

**驗證方法**：
```python
# 修改 custom_stoploss
if atr_pct < 0.005:  # 低波動
    return -0.01
elif atr_pct > 0.015:  # 高波動
    return -0.03
else:
    return -0.02
```

**預期效果**：減少在低波動時被短暫觸發止損，以及在高波動時被深度回調掃出。

---

### 改進 2：RSI 邊界緩衝區 - 避免在臨界值進場

- 收緊 RSI 範圍：35→40（避免過早進場搶反彈），72→68（避免追高）

**驗證方法**：

**預期效果**：犧牲少量進場次數，换取更高質量的進場點，止損交易減少。
