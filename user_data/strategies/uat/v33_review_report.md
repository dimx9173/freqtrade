## 3. 策略設計分析

### 3.1 v33 核心理念
- **突破策略**: 價格突破 N 期高/低點時進場
- **雙向交易**: 可做多也可做空
- **波動率過濾**: ATR Expansion + BB Width 確認趨勢

### 3.2 問題診斷

#### 問題 1: ATR Range 過度嚴格
```
設計值: 0.1% ~ 10% (ATR/Price)
實際數據觀察:
- 5m 圖 ATR% 通常在 0.4% ~ 0.8% 區間
- v33 的 min_atr_pct = 0.001 理論上應通過
- 但 combination filter 導致全部被過濾
```

#### 問題 2: Spread 計算可能不正確
```
問題: 5m K線的 high-low spread 通常 > 2%
設計: max_spread_pct = 0.05 (5%)
觀察: 真實 spread 範圍 0.3% ~ 1.5%

即使放寬到 5%，若實值是 1.5%，看起來會通過
但與其他 filters 組合後全部失敗
```

#### 問題 3: Donchian 突破條件極難觸發
```
donchian_period = 12 (60分鐘窗口)
在 5m 圖表上，60 分鐘等於 12 根 K 線

問題:
- 價格需要突破過去 12 根 K 線的最高/最低點
- 這個條件在震盪市場幾乎不會發生
- 需要很強的趨勢才能觸發

對比 v28:
- v28 使用 EMA 交叉 + RSI 回調
- 進場條件是 EMA 多頭排列 + 價格小幅回調
- 更容易觸發，產生 4,103 筆交易
```

#### 問題 4: 多重過濾疊加效應
```python
# 所有條件都必須滿足 (AND)
enter_long = (
    cond_breakout_up &      # 必須突破
    cond_atr_range &        # ATR 範圍
    cond_spread &           # 價差
    cond_volatility &       # 波動率
    cond_vol_expansion &    # 波動擴張
    cond_volume             # 成交量
)
```
**問題**: 6 個條件全部 AND，導致通過率極低

## 6. 結論與建議

### 6.1 結論: ❌ **需要調整** (Not Approved)

**核心問題**: v33 策略無法產生任何交易，策略設計存在根本性問題

### 6.2 下一步建議

#### 建議 1: 簡化進場條件
```
當前: 6 個 AND 條件全部必須滿足
建議: 降低為 2-3 個核心條件

範例:
enter_long = (
    (close > dc_high) &           # 突破
    (volume_ratio >= 1.5)        # 成交量確認
)
```

#### 建議 2: 調整 Donchian 週期
```
當前: donchian_period = 12 (60 分鐘)
問題: 窗口太短，容易盤整

建議測試:
- donchian_period = 24 (2 小時)
- donchian_period = 48 (4 小時)
- donchian_period = 96 (8 小時)
```

#### 建議 3: 添加「或」邏輯
```
當前: 所有條件 AND
建議: 核心條件 OR 備選條件

範例:
enter_long = (
    (close > dc_high) & cond_volume  # 突破 + 成交量
) | (
    (close > dc_high) & cond_volatility  # 突破 + 波動率
)
```

#### 建議 4: 放寬 ATR/Spread 限制
```
當前: ATR range + spread 過濾可能過度嚴格
建議: 僅保留核心過濾 (成交量或波動率)
```

#### 建議 5: 回測 v28 確認基準
```
如 v28 回測結果穩定:
- 建議基於 v28 修改，而非從頭設計 v33
- 可以添加 dual-direction，但保持 EMA 進場觸發
```
